# Reports and changes

- <agent-name>/YYYY-MM-DD_HHmmss_slug.md — self-contained agent reports.
- [reviewer/issues.md](reviewer/issues.md) — working list of implementation defects.
- [flags.md](flags.md) — working list of questions requiring human decisions.
- [summaries](summaries/README.md) — batch summaries between commits.

Time zone: Asia/Novokuznetsk (UTC+07:00). Preserve history; record new work in
separate files using the [report template](../sdd/report-template.md).
Remove closed items from working lists only after preserving decisions and
evidence in dated reports or summaries. Before a commit message, both lists
contain only their heading and purpose description; never hide unresolved issues.
