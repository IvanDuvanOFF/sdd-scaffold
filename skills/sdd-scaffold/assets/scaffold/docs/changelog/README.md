# Отчёты и изменения

- <agent-name>/YYYY-MM-DD_HHmmss_slug.md — самодостаточные отчёты агентов.
- [reviewer/issues.md](reviewer/issues.md) — рабочий список дефектов реализации.
- [flags.md](flags.md) — рабочий список вопросов, требующих решения человека.
- [summaries](summaries/README.md) — итоговые сводки наборов между коммитами.

Часовой пояс: Asia/Novokuznetsk (UTC+07:00). История сохраняется, новые выполнения
пишутся отдельными файлами по [шаблону отчёта](../sdd/report-template.md).
Закрытые пункты удаляются из рабочих списков только после сохранения решений
и доказательств в датированных отчётах/сводке. Перед коммит-месседжем оба списка
содержат только заголовок и описание назначения, без скрытия нерешённых проблем.
