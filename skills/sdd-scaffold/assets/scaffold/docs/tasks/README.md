# Задания

Отдельный файл <agent-name>/<task-id>.md на поручение, по
[шаблону](../sdd/task-template.md). Координатор создаёт и назначает задания,
исполнитель сохраняет самостоятельный отчёт в docs/changelog/<agent-name>/.

Задания — рабочие документы. Documenter удаляет только завершённые задания
принятого набора после подготовки запрошенного коммит-месседжа и сохранения
содержания, AC, проверок и решений в постоянных отчётах и сводке. Остальные
задания сохраняются. Сообщение не требуется — автоматической очистки нет.
