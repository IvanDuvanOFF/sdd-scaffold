# Assignments

Use one <agent-name>/<task-id>.md file per assignment, using the
[template](../sdd/task-template.md). The coordinator creates and assigns work;
the executor saves a separate report in docs/changelog/<agent-name>/.

Assignments are working documents. Documenter deletes only completed assignments
in an accepted batch after preparing the requested commit message and preserving
contents, AC, checks, and decisions in permanent reports and the summary. Keep
all other assignments. If no message is requested, there is no automatic cleanup.
